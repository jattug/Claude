# Trading journal

**[`forge/`](./forge)** — Forge, a process-first swing trading journal built on the principles
in *The Disciplined Swing Trader*. It scores your discipline rather than your P&L: a winning
trade taken against your rules is recorded as a mistake, a losing trade taken perfectly as a
success.

See [forge/README.md](./forge/README.md) for what it captures and why, and for how to run it.

```bash
cd forge && npm install && npm run dev
```
